# Claude Theft Auto: Bombay

A mini-GTA in Three.js set only in **Marine Drive + Fort**, South Mumbai — dusk over the Arabian Sea, the
Queen's Necklace, Art Deco and Victorian Gothic streets, kaali-peeli taxis, BEST buses, crowds and cops.

**Play:** https://adi-devv.github.io/claude-theft-auto-bombay/

**Run locally:** `python3 -m http.server 8765 --bind 127.0.0.1` from this folder → http://localhost:8765/game/

Built by a team of Claude agents (one builder per system + harsh critic agents that play the running game).
Contributors / new sessions: start with [HANDOFF.md](HANDOFF.md), then [game/CONTRACT.md](game/CONTRACT.md).
